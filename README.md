# Medicine-Expiry-Tracker-app

A Streamlit web application designed to help users track the expiry dates of their medicines. The app allows users to add medicine details such as name, batch number, expiry date, barcode, and quantity. It displays a list of all medicines with their expiry status, highlighting those that are expired or expiring soon.

## Features

- Add medicine details: name, batch, expiry date, barcode, and quantity
- View all medicines with expiry status (expired, expiring soon, or safe)
- Delete medicines from the list
- Clean and intuitive user interface with a custom background
- Real-time expiry tracking and status alerts

## Technologies Used

- Streamlit (for the web interface)
- SQLite (for storing medicine data)
- Python (core language)

## Usage

- Start the app with `streamlit run app.py`
- Add medicine details using the form
- View the list of medicines with expiry status
- Delete medicines as needed

## Project Structure

- `app.py`: Main Streamlit application file
- `medicine_expiry.db`: SQLite database for storing medicine data
- `requirements.txt`: Lists required Python packages
